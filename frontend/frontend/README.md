# DevelopersHub Full-Stack Web Application

## 📌 Project Overview
This is a full-stack web application built as part of a Full-Stack Development Internship.

The platform represents an agency system where users can explore services, contact the team, and book meetings. An admin panel is also included to manage data.

---

## 🚀 Features

### User Side
- View services
- Contact form (store inquiries)
- Booking system (schedule meetings)

### Admin Panel
- Admin login (JWT authentication)
- View contacts
- View bookings
- Delete contacts and bookings

---

## 🛠️ Tech Stack

Frontend:
- React (Vite)
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB (Mongoose)

Authentication:
- JWT (JSON Web Token)

---
